## About

I'm the **first engineer at [Auria AI](https://auria-ai.com.br)**, where we build AI agents
for monitoring centers and physical security in Brazil. I designed and built the product from
the ground up — from the original proof of concept through the MVP that helped the company
raise a seed round from international VCs. Today I focus on agent architecture, code quality,
and mentoring a growing engineering team.

Most of my work outside that has been closer to the metal. I've written a **FAT filesystem**,
an **AMQP message broker** and a **process scheduler** from scratch in C, and contributed
**KUnit test suites to the Linux kernel's AMD Display driver**, reviewed on the `amd-gfx`
mailing list.

I also care about the community I came up in: I led **FLUSP** (USP's free-software group),
served as **President** and now **Advisor** of **USPCodeLab**, and kept the **IME-USP
GNU/Linux network** running for 300+ users.
